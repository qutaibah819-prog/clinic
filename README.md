Klinik 24 — Healthcare Website
A responsive healthcare website built by transforming a visual design concept into a functional web experience. The project presents medical services, clinic information, appointment reservation calls to action, partner organizations, and patient testimonials in a clean, modern layout.
Project Overview
Klinik 24 is a healthcare landing page concept designed to help visitors explore available medical services and easily find ways to book an appointment. The website focuses on a clear user experience, a friendly medical aesthetic, and a layout that remains accessible and visually consistent across different screen sizes.
Technologies Used
- Next.js — React framework used to build the website.
- TypeScript — Adds static typing and helps write more reliable, maintainable code.
- Tailwind CSS — Utility-first CSS framework used to style the interface and build responsive layouts.
Design to Web
The website was developed from a provided visual design reference and recreated as a real web interface. During implementation, I aimed to preserve the original design as closely as possible—including its layout, visual hierarchy, colors, spacing, typography, cards, imagery, and overall feel—while adapting the elements to work naturally on the web.

Rather than reproducing the design only for one screen size, I made the layout responsive so it can adjust to desktop, tablet, and mobile screens.
Sections
- Hero section: Introduction to Klinik 24, with a headline, supporting text, and prominent actions.
- Partners: A row of healthcare partner logos.
- Medical services: Service cards highlighting offerings such as a 24-hour pharmacy, medical checkups, and professional doctor services.
- Clinic introduction: A section featuring clinic imagery and information.
- Facilities: A section presenting the clinic's facilities and patient-focused experience.
- Appointment call to action: A prominent section encouraging visitors to reserve a service or check a doctor's schedule.
- Patient testimonials: Testimonial cards displaying patient feedback.
- Footer: Contact information, company links, branch information, and social links.
Responsive Design
The interface is designed to provide a consistent experience across a range of screen sizes:
- Desktop: Maintains the original multi-section layout and visual composition.
- Tablet: Adjusts spacing, sizing, and section layouts to fit medium screens.
- Mobile: Reorganizes content into a more compact, readable layout with comfortable spacing and accessible controls.
The goal was to preserve the design's identity while ensuring that content remains readable, usable, and well arranged on smaller screens.
SEO & Accessibility Improvements
I also contributed to improving the website's search-engine optimization (SEO) and accessibility by following several important practices:
- Added appropriate metadata to provide search engines with relevant information about the pages.
- Set explicit image dimensions to help prevent layout shifts and improve page-loading experience.
- Used Next.js Image component to benefit from its image optimization features.
- Added descriptive alt attributes to images to improve accessibility and help search engines understand image content.
- Used h1 headings selectively, reserving them for the page's primary heading and maintaining a meaningful heading hierarchy.
Goals
- Turn a static design reference into a functional website.
- Maintain visual fidelity to the original design as much as possible.
- Build a responsive layout for desktop, tablet, and mobile.
- Apply SEO-conscious and accessibility-minded practices.
- Create a clear and intuitive user experience.
- Practice front-end implementation, layout structure, and responsive design.
